# 🌌 BEYOND
**Made in C++**

> Build the rocket. Leave Earth. Explore the unknown.

**BEYOND** is an open-world space exploration game featuring a procedurally generated universe filled with unique planets, alien life and mysteries.

## 🎮 Features
- 🌍 Start on Earth and build your first rocket.
- 🚀 Explore planets, moons, and star systems.
- 🪐 Discover unique environments and ecosystems.
- 👽 Encounter unique aliens.
- ⛏️ Collect resources, craft, and trade.

## 🌠 The Goal
Create a universe where every planet is different and every journey brings something new.

**Start with nothing. Build your rocket. Discover BEYOND.**
